# Regularization-of-Machine-Learning-Models

Ce projet démontre différentes techniques de régularisation pour améliorer les performances des modèles de machine learning et éviter le surapprentissage.

## Contenu

- `mini_projet_regularisation.ipynb`: Notebook Jupyter présentant:
  - Régularisation L1 (Lasso)
  - Régularisation L2 (Ridge)
  - Elastic Net (L1 + L2)
  - Comparaisons et visualisations

## Installation

```bash
pip install -r requirements.txt
```

## Utilisation

```bash
jupyter notebook mini_projet_regularisation.ipynb
```

## Techniques couvertes

1. **Régression linéaire sans régularisation** - Modèle de base
2. **Ridge (L2)** - Pénalisation des coefficients élevés
3. **Lasso (L1)** - Sélection automatique des caractéristiques
4. **Elastic Net** - Combinaison de L1 et L2
